# Interactive To-Do List Application // Frontend Internship Task

A modern, responsive, and feature-rich productivity dashboard application built with Vanilla JavaScript, HTML5, and CSS3. Developed as part of the Frontend Development Internship task.

## 🚀 Live Demo
* **Live Website URL:** [View Live App](https://saranyak449.github.io/interactive-todo-app/) 

## ✨ Features
* **Modern Dashboard UI:** Clean, light-themed productivity design featuring professional indigo and teal accent styling, rounded cards, and smooth transitions.
* **Task Management:** Add, complete, and delete individual tasks safely with XSS-resistant rendering (`textContent`).
* **Due Date Tracking:** Integrated date picker to assign and track task deadlines.
* **Live Filtering:** Seamlessly toggle between **All**, **Active**, and **Completed** task views.
* **Progress Tracking & Statistics:** Real-time visual progress bar, percentage completion badge, and dynamic item counters.
* **Data Persistence:** Fully integrated with browser `LocalStorage` so tasks remain saved across page refreshes and browser restarts.
* **Validation & Empty States:** Clean error feedback for empty submissions and intuitive empty state placeholders.

## 🛠️ Technology Stack
* **HTML5:** Semantic document structure and accessible form controls.
* **CSS3:** Flexbox, CSS Grid, Custom Properties (Variables), Responsive Media Queries.
* **JavaScript (ES6+):** DOM manipulation, event handling, state management, and LocalStorage API.
* **Development Tool:** Visual Studio Code with Live Server extension.
